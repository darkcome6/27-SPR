# 09 · 项目协作与赛季管理

> 项管视角的落点。**制度驱动，不靠人治**——本章是整套培训从"技术"走向"组织"的关键一跃。

## 本章要回答的核心问题

一个人的精力撑不起一个赛季。怎么靠流程、清单、机制把战队的技术下限抬起来？
