# 05 · 通信与协议："翻译官"能力

> 机器人是分布式系统：MCU 之间、电机之间、与裁判系统之间，全靠协议说话。通信能力 = 团队协同能力。

## 本章要回答的核心问题

让两个芯片"说同一种语言"，并且说得**可靠**，需要什么？
