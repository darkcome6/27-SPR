# 2.2 · 编程语言：C 语言速成（面向电控）

> **一句话本质：C 是机器人世界的通用语言——它离硬件最近，也最不惯着你。**

## 为什么单独开一节

往届的坑很一致：C 语言学了一整个学期，范围极广，新生却抓不到重点——学完还是看不懂队里的代码。

所以这节换个思路：**只讲队里代码反复用到的那部分 C，讲透，够用就行。**

队里代码里高频出现的其实就这几样：

- 变量、数组（`chassis[4]`）
- 函数（形参、实参、返回值）
- 结构体（**每个线程一个大结构体**）
- 循环与分支（`for` / `while` / `switch case`）

其他的语法，用到再查。**语法不熟没人笑你，但看不懂队友的代码，才真的寸步难行。**

## 怎么学（别背语法）

1. **先跑通再理解**：代码复制进工程，让灯亮、让串口出字，比看十遍书有用。
2. **多问一句"背后发生了什么"**：`HAL_GPIO_WritePin` 不是魔法，它只是往一个寄存器里写了个值。
3. **AI 当"第二大脑"，别当"作业代写机"**：让它解释、让它举例，然后**自己改一个数看结果变不变**。
4. **报错别慌**：C 的报错经常很原始，学会看"第一个报错"和它指向的行号。
