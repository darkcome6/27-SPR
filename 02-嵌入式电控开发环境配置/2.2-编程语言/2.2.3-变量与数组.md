# 2.2.3 变量与数组

> **一句话本质：变量 = 一块有名字的内存；数组 = 一排连续的、共用一个名字的内存。**
>
> 名字是给人看的，**地址**才是给机器看的。类型只决定两件事：**占几个字节**、**这几个字节怎么解释**。

---

## 一、类型决定了什么

```c
uint8_t  rx_byte;             // 1 字节，0 ~ 255
int16_t  speed;               // 2 字节，-32768 ~ 32767
float    kp;                  // 4 字节，浮点
```

| 类型 | 字节 | 范围 / 精度 | 队里常见用途 |
|---|---|---|---|
| `uint8_t` | 1 | 0 ~ 255 | 串口收到的字节、状态标志 |
| `int8_t` | 1 | -128 ~ 127 | 小范围有符号值（如编码器方向） |
| `uint16_t` | 2 | 0 ~ 65535 | 定时器计数值、PWM 比较值 |
| `int16_t` | 2 | -32768 ~ 32767 | 电机转速、位置增量 |
| `uint32_t` | 4 | 0 ~ 4294967295 | 时间戳、计数器 |
| `float` | 4 | 约 7 位有效数字 | PID 参数、角度、速度（**队里主力**） |
| `double` | 8 | 约 15 位有效数字 | 单片机上尽量别用，见下 |

**为什么嵌入式偏爱 `uint8_t` 这种"带位数"的写法，而不是 `int`？**
因为 `int` 到底几字节**看平台**，而通信协议、寄存器、报文都是**按字节数**定义的——
写 `uint16_t` 才是"我明确知道它是 2 字节"。

## 二、两个必须知道的坑

### 1. 溢出 / 有无符号

```c
uint8_t x = 255;
x = x + 1;         // x 变成 0，不是 256！（超过能存的最大值就绕回去了）
```

```c
uint16_t a = 0;
int16_t  b = -1;
if (a > b) { ... }   // 直接比较有坑：无符号和带符号混着比，结果反直觉
```
**规则：同一个比较/运算里，别把有符号和无符号混用。** 需要的话显式强转。

### 2. `float` 和 `double` 不是随便选的

- `double` 占 8 字节，精度高，但 **STM32F4 的硬件浮点单元（FPU）只算单精度**，
  双精度运算要靠软件模拟，**慢几十倍**（H7 才有双精度 FPU）。
- 所以队里统一用 **`float`**：写小数记得带 `f`，如 `1.2f`，让编译器知道这是单精度，别拿去和 `double` 计算。

> 结论：**能用 `float` 就用 `float`；不是精度真不够，不上 `double`。**

## 三、数组：一排连续的格子

```c
int16_t chassis[4];     // 4 个 int16_t，挨着放在内存里，共 8 字节
```

内存里大概长这样（地址只是示意）：

| 地址 | 元素 |
|---|---|
| 0x20000000 | `chassis[0]` |
| 0x20000002 | `chassis[1]` |
| 0x20000004 | `chassis[2]` |
| 0x20000006 | `chassis[3]` |

**为什么下标从 0 开始？**
因为下标本质是**偏移量**：`chassis[0]` = 首元素自己（偏移 0）。`chassis[2]` = 从首地址往后数 2 格。

### 队里的典型用法

```c
#define MOTOR_NUM 4

int16_t target[MOTOR_NUM];     // 输入：4 个轮子的目标转速
int16_t actual[MOTOR_NUM];     // 输入：4 个轮子的实际转速
int16_t output[MOTOR_NUM];     // 输出：最终给电机的值
```

下标和轮子一一对应：`target[0]` 是 1 号轮……**这种"一一对应"是嵌入式里最常见的约定，务必写进注释。**

```c
for (uint8_t i = 0; i < MOTOR_NUM; i++) {
    output[i] = target[i] - actual[i];
}
```

用 `MOTOR_NUM` 而不是写死 `4`：以后变 6 轮，只改一处。

### 初始化

```c
int16_t arr[4] = {0};              // 全部清零（最常用）
int16_t arr2[3] = {10, 20, 30};    // 逐个给初值
```

## 四、常见坑

1. **越界**：`chassis[4]` 是第 5 个元素——C **不检查**，你改的是别人的内存，症状通常莫名其妙。
2. **数组不能整体赋值**：`a = b;` ❌，要循环拷贝或 `memcpy(a, b, sizeof(a));`
3. **用 `sizeof` 数个数**：
   ```c
   uint8_t n = sizeof(chassis) / sizeof(chassis[0]);   // 元素个数，而不是字节数
   ```
4. **局部数组没初始化**，值是**随机的**（全局变量才默认是 0）。
5. **循环条件写成 `i <= 4`**：4 个元素的下标是 `0 ~ 3`，`<=` 越界。
