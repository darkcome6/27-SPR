# 2.3.6 外设：单片机的手和脚

> **一句话本质：CPU 负责想，外设负责干。**
> 凡是"等一个时间、数一堆脉冲、搬一批数据、把模拟变成数字"的活，都该交给外设。

---

## 一、为什么要有外设

用 CPU 硬干也能实现，但代价极大：

| 要干的事 | CPU 硬干的代价 |
|---|---|
| 精确发一个 1 ms 的高电平 | CPU 得一直盯着，什么都干不了 |
| 数编码器脉冲 | 高速转动时根本数不过来 |
| 收一串 100 字节的串口数据 | 每个字节都要轮询等待 |
| 采电压 | 还要自己理解"模拟量"，CPU 根本不会 |

**外设就是"专用硬件"**：你把参数配好，它自己按规则干活，完事了**中断**通知你一声（2.3.2）。
CPU 从容地去做决策 —— 这才是嵌入式的正确分工。

---

## 二、队里常见外设清单

| 外设 | 干什么 | 智能小车上的典型用途 |
|---|---|---|
| **GPIO** | 读 / 写引脚电平 | 按键、LED、电机使能、蜂鸣器 |
| **EXTI** | 引脚电平一跳就中断 | 限位开关、编码器 Z 相、外部触发 |
| **TIM** | 定时 / 计数 / **PWM** / 输入捕获 / 编码器接口 | 控制周期、电机 PWM、舵机、读编码器 |
| **UART / USART** | 异步串口 | 上位机通信、调试打印、遥控接收 |
| **SPI** | 高速同步串口 | IMU（陀螺仪）、外部 Flash |
| **I2C** | 两线慢速总线 | 磁力计、OLED、EEPROM |
| **ADC** | 模拟量 → 数字量 | 电池电压、电流采样 |
| **DMA** | **不占 CPU** 搬数据 | 串口收发、ADC 采样转运 |
| **CAN** | 抗干扰总线 | 底盘 / 机械臂 / 各板之间通信 |
| **IWDG / WWDG** | 看门狗：程序卡死就自动复位 | 保命（一定要开） |

> 每个外设的详细用法，在 **03 章（核心外设）** 和 **04 章（通信）** 里逐个上手。本节只要求"认识脸"。

## 三、学习顺序（别乱序）

```
GPIO ──> 定时器中断 ──> PWM ──> 串口 ──> I2C / SPI ──> ADC / DMA ──> CAN
（点灯）（周期任务）    （转电机）（和人对话）（接传感器）  （读模拟量）  （多板通信）
```

**为什么这个顺序？**
每一级都建立在前面一级上：没有定时器就不会有稳定的 PWM；没有串口就没法"看见"程序内部在干嘛。
**跳着学的结果是：每个外设都会配，但一出问题就完全不会查。**

## 四、面对"任何一个新外设"的五问

这是本节真正要教会你的东西——**套路比知识值钱**：

1. **硬件**：它接在哪几根引脚上？引脚复用功能是不是要改？
2. **时钟**：它的时钟从哪来？使能位叫什么？（2.3.4，**第一大坑**）
3. **寄存器**：它有哪些关键寄存器？关键位是什么？（2.3.5 + 参考手册）
4. **流程**：它的典型工作流程 / 时序是什么？（配参数 → 启动 → 收发 → 关停）
5. **中断 / DMA**：它怎么通知我？要不要用 DMA 搬数据？中断里该干多少活？

**拿着这五问去啃一个新外设，比漫无目的地看教程快得多。**

---

## 五、常见坑

1. **引脚被复用功能占走**：同一根引脚不能既做 UART_TX 又当普通 GPIO。**冲突时表现为"其中一个莫名失效"**，先查 CubeMX 的引脚分配图。
2. **外设时钟没开** → 配了没反应（2.3.4）。
3. **中断优先级冲突**：高优先级中断里的任务太长，或两个中断互相等着对方 → 卡死。
4. **`volatile` 忘了加**：中断改了变量，主循环却"看不见"（2.2.8）。
5. **DMA 的缓冲区被改写**：CPU 正在读，DMA 同时在写 → 数据对不上（要算清"半传输 / 全传输"的时机，04 章细讲）。
6. **只测"通了"，不测"错了怎么办"**：超时不处理、错误标志不清 → 现场偶发死机。
