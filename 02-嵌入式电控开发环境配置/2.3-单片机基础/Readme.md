# 2.3 · 单片机基础：你手里的这块芯片里有什么

> **一句话本质：单片机就是把一台电脑的"最小必要零件"塞进一块芯片里。**
> 你不必会造它，但必须知道它由哪几块组成——**因为每一个"玄学 bug"都能对应到其中一块。**

---

## 为什么先讲这个再写代码

2.2 讲完 C 语言，你已经有"写字"的能力，但还不知道"字写在哪"。
这一节只回答一个问题：**我写的代码，最后跑在什么东西上？**

答清楚这句话，后面几章（GPIO、定时器、串口、PWM）你才会知道自己在操作什么。

## 怎么学

1. **先建立"整机图"**：五块各自干嘛、怎么连起来，比抠某个寄存器更重要。
2. **对照实物**：拿一块自己的板子，找到晶振、找到主控、找到调试口，看得见就记得住。
3. **解释现象而不是背结论**："程序跑飞了"到底是 CPU、Flash、RAM 还是外设的问题？能定位到块，就算学会了。
