# 2.3.2 计算核心：CPU

> **一句话本质：CPU 只会做一件事——取指令、译码、执行，然后无限重复。**
> 所谓"程序跑起来"，就是它把这个循环转了几亿次。

---

## 一、三步循环

```
┌──────────┐   ┌──────────┐   ┌──────────┐
│  取指令   │ → │  译码     │ → │  执行     │ ─┐
│ 从 Flash  │   │ 这条要干嘛│   │ 算 / 读 / 写│  │
└──────────┘   └──────────┘   └──────────┘  │
       ▲                                     │
       └─────────────────────────────────────┘
```

翻译成人话，看一行 C 代码发生了什么：

```c
output[0] = target[0] - actual[0];
```

1. **取指令**：CPU 从 Flash 里取来一条机器码，大意是"把某个地址的数取出来"。
2. **译码**：哦，是要做减法，数据在 `target[0]` 和 `actual[0]` 对应的内存地址。
3. **执行**：读两个数 → 相减 → 把结果写回 `output[0]` 的地址。

**CPU 从不"理解"你的代码。** 它只是一条条地读机器码、照着做（对照 2.2.7：机器码是编译出来的）。

---

## 二、主频是什么

- **主频** = CPU 每秒经历的时钟节拍数。168 MHz = 每秒 1.68 亿次节拍。
- 一条简单指令往往只花一两个节拍，所以主频越高，单位时间能干的活越多（**粗略理解即可，别拿它做精确换算**）。
- 常见参考（以 STM32 为例）：

| 系列 | 内核 | 主频（典型） | 特点 |
|---|---|---|---|
| F1 | Cortex-M3 | 72 MHz | 经典入门 |
| F4 | Cortex-M4F | 168 MHz | **带单精度硬件浮点（FPU）** |
| H7 | Cortex-M7 | 400~480 MHz | 性能怪兽，带双精度 FPU |

> **为什么队里用 `float` 不用 `double`？** 因为 F4 的 FPU **只算单精度**（2.2.3）。
> 这就是"CPU 决定了你能用什么数据类型"的真实例子——不是习惯问题，是硬件问题。

## 三、单片机 CPU 的取舍：不追求最快，追求"确定"

| | 手机 / 电脑 CPU | 单片机 CPU |
|---|---|---|
| 主频 | GHz 级 | 十几 ~ 几百 MHz |
| 缓存 / 乱序 | 有，极复杂 | 基本没有，简单直接 |
| 运行环境 | 操作系统调度、有 GC | 裸机或 RTOS，你说了算 |
| 追求 | 平均性能高 | **最坏情况下的时间可预测** |

**为什么"可预测"这么重要？**
你的控制循环要**每 1 ms 准时**跑一次。电脑上程序被系统打断一下毫无感觉；机器人上，周期抖动 5 ms 可能就是车抖、翻车。
**实时性 = 确定性，比"快"更值钱。**

## 四、CPU 不是万能手（认识这一点，才算入门）

很多人（包括以前的我们）第一反应是："什么都能用 CPU 干啊，写个循环不就行了？"
但嵌入式设计恰恰相反：**能让外设干的活，绝不占 CPU。**

| 任务 | 新手写法 | 正确姿势 |
|---|---|---|
| 等 1 ms | `for` 空转 | 定时器 + 中断 |
| 数编码器脉冲 | 循环里读引脚 | 定时器编码器模式 / EXTI |
| 串口收 100 字节 | 每字节轮询等 | 串口中断 + DMA |
| 采集电压 | 循环里读 ADC | ADC + DMA |

**内核只做两件事：做决策、算结果。搬数据、定时、数脉冲，全交给外设。**
（`for` 空转为什么不行？它把 CPU 锁死在原地，别的活一秒都干不了。）

## 五、顺带认识一个词：中断

CPU 正跑着代码，外设举手："我有事了！" →

1. CPU 记下手头的进度（保存现场）
2. 跳到对应的**中断服务函数**（IRQ Handler）执行几行
3. 回到刚才的位置继续（恢复现场）

**有了中断，外设才能和 CPU 并行工作**：
你不用一直问"串口来数据了吗"，数据来了它会自己叫你。

中断怎么写、优先级怎么排，留到 03 章（定时器）和 04 章（通信）细讲，这里只要知道它存在。
