# 2.3.1 单片机的组成

> **一句话本质：单片机 = 把一台电脑的"最小必要零件"，全部塞进一块芯片里。**
>
> "单片"两个字就是这个意思：**一个芯片**，不用外接内存条、不用外接硬盘。

---

## 一、和一台台式机对照着看

| 家里的电脑 | 单片机里的东西 | 干什么 | 去掉会怎样 |
|---|---|---|---|
| CPU | **CPU 核心**（Cortex-M） | 算数、执行指令、做决策 | 什么都不会发生 |
| 内存条 | **SRAM**（RAM） | 运行时存变量、栈 | 程序一跑就崩 |
| 硬盘 | **Flash**（ROM） | 存程序，掉电不丢 | 上电没有程序可跑 |
| 主板晶振 / 时钟发生器 | **晶振 + 时钟树（PLL）** | 提供心跳，决定跑多快 | 一条指令都不执行 |
| 各种板卡（网卡、声卡…） | **外设**（GPIO / UART / SPI / TIM / ADC…） | 和外部世界打交道 | 芯片自己跟自己做游戏 |
| 操作系统 | **你的 C 代码**（裸机）或 RTOS | 决定这台机器干什么 | 机器不知道要干嘛 |

**一句话：单片机是"电脑的最小闭环"**——只要还能算、能存、有时钟、能接外设，就能跑起来。

---

## 二、它们是怎么连起来的

```
                    ┌──────── 时钟（心跳，2.3.4）────────┐
                    │                                   │
   ┌─────────┐  取指令   ┌─────────┐  写寄存器  ┌─────────┐  引脚
   │  Flash  │ ────────> │   CPU   │ ─────────> │  外设   │ ──────> 电机 / 传感器 / 上位机
   │（2.3.3）│           │（2.3.2）│            │（2.3.6）│
   └─────────┘           └────┬────┘            └─────────┘
                              │  ↑
                         写 / 读 │  │
                              ▼  │
                        ┌──────────┐
                        │   SRAM   │  （变量、栈）
                        └──────────┘
```

**看懂这张图，本节就过了**：

- 代码存在 **Flash**，CPU 从那里**取指令**。
- 数据（变量）放在 **SRAM**。
- CPU 想指挥硬件 → 只能通过**写寄存器**（2.3.5），没有别的办法。
- 一切都靠**时钟**打节拍（2.3.4）。

> 想验证"CPU 只能通过写寄存器控制外设"？回头看 2.2.1 那行"魔法代码"，以及 2.3.5。

## 三、三个容易混的词

| 词 | 是什么 |
|---|---|
| **单片机（MCU）** | 那颗芯片本身，如 STM32F407**ZGT6** |
| **开发板** | 芯片 + 晶振 + 电源 + USB 转串口 + 调试口 + LED…… 的"生活配套" |
| **最小系统板** | 只保留"能让芯片跑起来"的最少外围（供电、晶振、复位、下载口） |

**入队契约里让你点灯的那块板子**，就是开发板或最小系统板——真正常用的那部分，其实只有中间那颗芯片。

## 四、为什么必须懂"组成"

因为**每一个玄学 bug，都能定位到上面那块**：

| 现象 | 先怀疑哪块 |
|---|---|
| 上电完全没反应，连调试器都连不上 | 供电 / 晶振 / 复位（2.3.4） |
| 烧录成功，但引脚电平不动 | 外设时钟没开 / 寄存器没配对（2.3.4、2.3.5） |
| 运行一会儿就重启 | 看门狗 / 栈溢出（2.3.3、2.3.6） |
| 变量值莫名其妙被改 | 数组越界踩了内存（2.3.3 + 2.2.3） |
| 跑得很慢、周期不准 | 主频 / 时钟配置（2.3.4） |
| 换个变量改改现象就变了 | 栈溢出或未初始化变量（2.3.3） |

**这张表建议抄进笔记。** 后面几章学外设时，你会反复回来查它。
