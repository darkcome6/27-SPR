# 04 · STM32 核心外设：场景驱动

> **核心立场**：不讲寄存器清单，讲"场景驱动"——每个外设都为了回答一个真实工程问题。

## 本章要回答的核心问题

这些外设不是考点，是工具。什么时候用它、怎么选、什么时候是负担？
