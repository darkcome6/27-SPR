# 06 · 控制算法："调参哲学"

> **核心立场**：不是公式堆砌，是"调参哲学"——参数背后是物理直觉，不是玄学。

## 本章要回答的核心问题

电机为什么需要反馈？P / I / D 各自在补什么洞？参数怎么试出来的？
