# 03 · 工程素养：公司化流程的移植

> **前置条件**：02 章体感已建立（LED、电机、串口）。本章把"野路子撞墙"的挫败感，转化为对规范的渴求——**规范是对痛苦的解药，不是额外的负担。**

## 本章要回答的核心问题

"能跑" ≠ "能交付"。公司的代码凭什么敢上线？SPR 凭什么敢上赛场？
