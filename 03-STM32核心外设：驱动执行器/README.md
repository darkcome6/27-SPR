# 04 · STM32 核心外设：场景驱动

> 江科大的课程周期较长，关于寄存器、通讯机制的摄入太深，新生想要彻底理解不现实，往往不知所云。
> 所以本章挑出**最常用的几节**详细讲解、节约时间——**内容尽量围绕校内赛（控制电机、舵机）的实际场景去介绍。**

## 本章要回答的核心问题

- 一根引脚，凭什么既能当"输入"，又能当"串口"，还能当"PWM"？
- 怎么让单片机**每隔 1 ms 准时**干一件事？（而不是靠 `for` 空转）
- 怎么让电机转起来、让舵机转到指定角度——而不是"照抄代码碰运气"？

## 本节的底线要求：不要背语法糖

> "GPIO 口常用的几个函数 置高电平 低电平 以及基本的配置 —— **简单介绍这些配置的意义即可，无需记忆语法糖，后期也只是迁移。**"

所以本章的评分标准是：

- **能不能讲清楚"为什么这么配"**（而不是能不能默写 `HAL_GPIO_WritePin`）。
- **换了芯片 / 换了库，你会不会迁移**（会查手册、会看框图，就不怕换）。
- 函数名忘了很正常，**去哪查、怎么验证**才是要练的。

## 交付与验收（本章总）

- [ ] 一个能用按键控制的 LED（3.1 + 3.2）
- [ ] 一个 1 ms 的周期任务，用实测（示波器 / LED 计时）证明周期正确（3.3）
- [ ] 一路 PWM 让电机稳定转动，一路 PWM 让舵机扫 0~180°（3.4）
- [ ] 每个现象都能用"寄存器 / 时钟 / 模式"三件套解释清楚
