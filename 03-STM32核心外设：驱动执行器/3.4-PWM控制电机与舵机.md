# 3.4 PWM：用 PWM 控制电机与舵机

> **一句话本质：PWM 不是"输出一个电压"，而是"用开和关的时间比例，让负载感受到一个中间值"。**
> 一根数字引脚只会输出高/低，PWM 让它"高一会儿、低一会儿"——**比例就是你要的模拟量。**

---

## 一、三个参数，决定 PWM 长什么样

```
        一个周期 T
   ┌───────────────┐
   │高电平 │  低电平 │
───┘       └─────────┘
   └─ 高电平时间 ─┘

占空比 = 高电平时间 / 周期 T
```

| 参数 | 含义 | 谁来决定 |
|---|---|---|
| **频率** | 一秒有多少个周期 | `PSC` + `ARR` 一起决定 |
| **占空比** | 一个周期里高电平占的比例（0~100%） | `CCR`（比较值）决定 |
| **分辨率** | 占空比能分成多少档 | `ARR` 决定（ARR=999 → 1000 档） |

**两条公式（够用一辈子）：**

$$
\text{PWM 频率}=\frac{\text{定时器时钟}}{(\text{PSC}+1)\times(\text{ARR}+1)}
\qquad
\text{占空比}=\frac{\text{CCR}}{\text{ARR}+1}
$$

**例（F4，定时器时钟 84 MHz，要 20 kHz 给电机）：**

- `PSC = 0`、`ARR = 4199` → 84 MHz / 4200 = **20 kHz** ✅
- `CCR = 2100` → 占空比 = 2100 / 4200 = **50%** ✅

**记住分工：`ARR` 定频率，`CCR` 定占空比。**
想调速 → 只改 `CCR`；**改 `ARR` 会把频率一起改掉**（这是新手常见的错）。

---

## 二、为什么电机能靠 PWM 调速

**关键：电机是一个"惯性 + 电感"系统，它跟不上 20 kHz 的开关速度，只能感受到"平均效果"。**

```
平均电压 = 母线电压 × 占空比
```

- 占空比 0% → 平均电压 0 → 不转
- 占空比 50% → 平均电压一半 → 半速（空载近似）
- 占空比 100% → 全速

**开关够快 → 宏观上等价于一个可调电压源。**
这就是"用数字手段实现模拟输出"，也是嵌入式最漂亮的一个技巧。
（对比：如果 PWM 频率低到 1 Hz，电机就会"一顿一顿"地转。）

> **为什么选 20 kHz？** 因为**人耳听觉上限约 20 kHz**——落在音频范围里，电机会"滋滋"叫。
> 所以有刷直流驱动器普遍用 **10~20 kHz**：听不见，开关损耗也可接受。

---

## 三、为什么舵机是靠 PWM "定角度"

**舵机完全是另一套逻辑：它不看占空比的比例，而是看"高电平有多宽（多少毫秒）"。**

| 项目 | 有刷电机（PWM 调速） | 舵机（PWM 定角） |
|---|---|---|
| 看什么 | **占空比比例** | **高电平的绝对时长（脉宽）** |
| 频率 | 10~20 kHz（越高越安静） | **必须 ≈ 50 Hz**（周期 20 ms） |
| 典型值 | 占空比 0~100% | 0.5 ms → 0°，1.5 ms → 90°，2.5 ms → 180° |
| 频率错了会怎样 | 只是叫得难听 / 发热 | **直接不动、抽搐、发抖** |

**为什么是 50 Hz？** 这是舵机内部电路定下的"约定"：它每隔 20 ms 收一次你的脉宽信号，据此把输出轴转到对应角度。
**我们必须遵守它的约定**——这不是"习惯"，是"协议"。

> **注意**：0.5~2.5 ms 对应 0~180° 是常见标称；**很多舵机出厂实际是 1~2 ms 对应 0~180°**。
> 所以：**第一次用某个舵机，先小范围试（比如 1.0~2.0 ms），确认不会顶到机械限位，再标定。**
> 硬顶限位会烧舵机齿轮——这是真金白银的教训。

## 四、代码：三步走

```c
/* ① 初始化：CubeMX 里把 PWM Generation 通道配好（频率 20kHz），
      并把该引脚自动设为"复用推挽"（3.1）                          */

/* ② 启动：必须显式 Start，否则引脚一点波形都没有（HAL 经典坑） */
HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);

/* ③ 用的时候只改 CCR */
__HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, 2100);      /* → 50% 占空比 */

/* 读回当前值（调试/限幅用） */
uint16_t ccr = __HAL_TIM_GET_COMPARE(&htim3, TIM_CHANNEL_1);
```

**电机调速就是不断改 `CCR`：**

```c
/* speed: -1000 ~ +1000，映射到 CCR 并限幅 */
void Motor_Set(uint8_t id, int16_t speed)
{
    if (speed >  1000) speed =  1000;         /* 限幅（2.2.4、2.2.6） */
    if (speed < -1000) speed = -1000;

    if (speed >= 0) {                         /* 正转 */
        HAL_GPIO_WritePin(DIR_PORT, DIR_PIN, GPIO_PIN_SET);
        __HAL_TIM_SET_COMPARE(&htim3, ch[id], (uint32_t)speed * PWM_ARR / 1000);
    } else {                                  /* 反转 */
        HAL_GPIO_WritePin(DIR_PORT, DIR_PIN, GPIO_PIN_RESET);
        __HAL_TIM_SET_COMPARE(&htim3, ch[id], (uint32_t)(-speed) * PWM_ARR / 1000);
    }
}
```

**舵机转到指定角度，就是换算成脉宽：**

```c
/* 计数器 1MHz（PSC=83），则 1 个计数 = 1 us；20ms 周期 → ARR = 19999 */
#define SERVO_MIN_US   500      /* 0.5 ms */
#define SERVO_MAX_US  2500      /* 2.5 ms */

void Servo_SetAngle(uint8_t id, uint8_t deg)     /* deg: 0~180 */
{
    if (deg > 180) deg = 180;
    uint32_t pulse = SERVO_MIN_US + (SERVO_MAX_US - SERVO_MIN_US) * deg / 180;
    __HAL_TIM_SET_COMPARE(&htim, ch[id], pulse);  /* 单位正好是 us */
}
```

## 五、一个重要区分：有刷驱动器 vs 无刷电调

**同样是"PWM 控电机"，但要求的信号完全不同**——搞错了电机就是不转：

| | 有刷电机 + 驱动器（BTS7960 / DRV8701 / L298N…） | 无刷电机 + 航模电调（ESC） |
|---|---|---|
| MCU 给什么 | 直接决定"平均电压"的 PWM | 给电调一个**舵机式信号**（脉宽 1~2 ms，50~400 Hz） |
| 谁负责换相 | 不用换相（有刷） | **电调内部负责换相**，还会做保护 |
| 频率 | 10~20 kHz | 50~400 Hz（或 DShot / 串口等数字协议） |
| 典型现象 | —— | 频率当 20 kHz 给 → **电调完全不动** |

> **一句话**：控制有刷电机，你在控制"电压"；控制无刷电调，你在给它"发指令"。
> **上电前先查驱动器/电调的手册**，别拿一套参数套所有电机。

## 六、安全设计（机器人代码的红线）

1. **上电默认为 0**：初始化完成后第一件事就是把所有 PWM 置 0，**绝不能"上电就冲出去"**。
2. **急停用使能脚，而不是"占空比设为 0"**：占空比 0 只是"自由停车"，EN 拉低才是**切断输出**。急停要可靠。
3. **失控保护**：遥控/上位机信号超时 → PWM 立刻归零（这是最基本的失效安全）。
4. **限幅 + 斜率限制**：突然 0 → 100% 会烧驱动、烧齿轮、让车打滑；加个斜坡或限加速度。
5. **共地**：驱动器、舵机、MCU 必须共地，否则信号乱飞。

---

## 七、常见坑

1. **忘了 `HAL_TIM_PWM_Start`** → 引脚没波形（HAL 最经典的坑，排第一）。
2. **引脚没配成复用推挽** → 定时器接管不了这根脚，输出还是 0（3.1）。
3. **改 `ARR` 来"调速"** → 频率被一起改了：电机叫、舵机抖。
4. **舵机频率配成 1 kHz** → 直接不动或抽搐（必须是 50 Hz）。
5. **舵机电源从 MCU 的 3.3 V 取** → 舵机一堵转，电压被拉垮，**单片机直接复位**。
   舵机必须**单独供电 + 共地**，并留足电流余量（堵转可达 1 A 以上）。
6. **MCU 是 3.3 V 逻辑，舵机要 5 V 信号** → 有些舵机认不出高电平 → 不动或乱动，需要电平转换或换 3.3 V 兼容舵机。
7. **没有示波器就"盲调"** → 一定要有手段验证波形（见验收）。
