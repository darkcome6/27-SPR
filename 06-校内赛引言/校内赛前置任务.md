# 校内赛前置任务

> **这份清单是干什么的？**
> 从校内赛的整条链路里切出来的练习点。**讲解只解决"看懂"，练习才解决"会做"。**
> 每一项都是**动手做 + 想明白**两件事，两件都做完才算过。

**校内赛要做的两件事**（来自 `校内赛的任务分析.pdf`）：

```
底盘   ：目标速度   → 运动学解算     → 4 个轮速 → 电机
机械臂 ：目标位姿   → 逆运动学解算   → 各个角度 → 舵机
```

两条链长得一模一样，都是 **输入数据 → 解算 → 输出数据 → 执行器**。
所以前置任务按「**单个外设 → 单条链路 → 闭环 → 整机**」的顺序排 —— 一条链学通了，另一条照搬。

## 〇、通用规则（先看这里，不然会白干）

### 0.1 怎么算"过"

**组长现场抽查 + 交付物存档。**

"我做完了"不算数 —— 要能**当场复现 + 讲清为什么**。组长会从验收标准里随机挑一条，让你现场做。

### 0.2 每次任务交三样东西

| 交付物 | 内容 | 为什么 |
|---|---|---|
| **代码** | 推到 GitHub，提交信息写清"改了什么、为什么" | 两周后你自己要看 |
| **现象证据** | 30 秒视频 / 波形截图 / 串口打印 | 口头描述 = 没有证据 |
| **一页实验记录** | 发生了什么 / 我做了什么 / 我猜是什么原因 | 见 0.3 |

### 0.3 提问三段式（硬性要求）

卡住了要问人，**必须**带上这三句：

1. **发生了什么** —— 现象、复现步骤、报错 / 波形
2. **我做了什么** —— 排查到哪一步了，砍掉了哪些可能
3. **我猜是什么原因** —— 你的假设

> ⚠️ **没有排查记录的提问，电控组不受理。**
> 不是为难你 —— "能把问题描述清楚"本身就是能力，也是你将来最值钱的东西。

### 0.4 卡住了怎么办（按时间递进，别越级）

| 卡住多久 | 该做什么 |
|---|---|
| **30 分钟** | **先把问题拆开**：能测的量先测（电压？波形？返回值？）—— 把"硬件有没有动"和"代码对不对"分开 |
| **1 小时** | 用**工具**看证据（示波器 / 调试器 / 串口打印），不许靠猜 |
| **2 小时** | 带着 0.3 的三段式找组长 / 学长 |

> 两个反面教材：卡了 2 分钟就问人；卡了 6 小时不吭声。**都是在浪费别人的时间。**

### 0.5 难度分档

| 档 | 含义 | 要求 | 大概工时 / 项 |
|---|---|---|---|
| **基础** | 单个外设能按你的命令动起来（**开环**） | **必做**，这是校内赛的门槛 | 2 ~ 4 小时 |
| **中等** | 加上反馈变成**闭环**；多个执行器配合出位姿 | 选做 —— 做完，整机就顺了 | 4 ~ 8 小时 |
| **困难** | 整机联调 + 鲁棒性 + 工程规范 | 选做 —— 做的人就是校内赛主力 | 8 小时以上 |

## 一、基础（必做）

### 任务 1｜PWM 控制舵机、电机

**做什么**

| 步 | 任务 | 应该看到 |
|---|---|---|
| 1 | 定时器输出一路 PWM，控制舵机 | 舵机平滑扫过 0° → 180° → 0° |
| 2 | 同一路 PWM 改成控制电机 | 转速从 0 均匀加到最大 |

**核心掌握（按顺序答，别跳）**

1. **角度 ↔ 脉宽**：舵机角度和脉冲宽度的换算公式是什么？
   把 90° 的脉宽**手算出来**，再用示波器量一次 —— **对得上吗？**
   > 提示：常见规格是周期 20 ms（50 Hz），0.5 ms ↔ 0°、2.5 ms ↔ 180°。
   > 也有 1 ~ 2 ms 规格的舵机，**以你手上那颗的手册为准**。
2. **舵机的零位是固定的吗？** 同一个舵机装到机械臂的另一侧，
   "代码里写 90°"还是同一个物理角度吗？
   > 提示：零位是在**舵机里面**，还是在**你的机械结构里**？
   > 再想一层：那机械安装要不要对齐？不对齐会怎样？
3. **停发 PWM 的时候，电机能急停吗？** 从**转矩（力）的角度**分析你看到的现象。
   > 提示：停发 PWM 后，电机绕组上还有电流吗？
   > 轮子是被什么力停下来的 —— 摩擦？反电动势？还是主动制动？
   > 如果要急停，怎么优化？（查你电调手册里的"刹车 / 空转 / 阻尼"设置）
4. **转速 ↔ 占空比**：占空比从 10% 加到 90%，转速是线性涨的吗？
   如果不是，猜猜为什么。
   > 提示：想一想低速段"转不动"（死区）和反电动势。

**验收标准（组长照这个打勾）**

- [ ] 现场说出"角度 → 脉宽"的换算，并当场算出一个指定角度
- [ ] 示波器截图 ×3：三个不同角度的脉宽，误差 < ±0.05 ms
- [ ] 能说清"零位在哪、要不要对安装"，并举一个**装错的反例**
- [ ] "停 PWM 能否急停"给出**带依据**的结论（手册原文 / 实测现象），不接受"我觉得"
- [ ] 能说出"占空比和转速为什么不线性"

### 任务 2｜串口通讯：用蓝牙遥控舵机和电机

**做什么**

| 步 | 任务 |
|---|---|
| 1 | 蓝牙模块接到串口，先做到**能收到**上位机发来的一个字节 |
| 2 | 定义一帧数据，里面带"舵机角度" → 舵机转到指定角度 |
| 3 | 扩展这一帧，加上"电机转速 + 正反转" |
| 4 | 故意发**坏数据**（丢字节 / 混噪声 / 乱序），看你的程序会怎样 |

**核心掌握（按顺序答，别跳）**

1. **中断处理程序怎么写？**
   直接在中断里处理数据，和"中断里只接收、中断外处理"，哪种更好？为什么？
   > 提示：中断里待久了会发生什么？谁会被耽误？
2. **有什么快捷高效的方式搬运数据？**
   > 提示：一个字节一个字节地拷，和一次搬一整块，谁快？有没有现成的库 / 函数？
3. **解包程序怎么写？怎么判断数据完整？怎么判断数据正确？**
   > 提示：帧头 + 长度 + 数据 + 校验（累加和 / CRC）—— 每一部分分别在防什么？
   > 再想：如果中间丢了一个字节，你的帧头和校验发现得了吗？
4. **串口的处理程序放在哪个位置才会被调用？有几个位置？**
   > 提示：查一下 HAL 库的**弱函数回调**机制（`HAL_UART_RxCpltCallback` 这类），
   > 它们分别在什么时候被触发。
   > 再想：DMA 接收 和 中断接收，回调有什么不同？
5. **通讯的核心本质是什么？你的解包程序是根据什么设计的？**
   > 提示：`校内赛的任务分析.pdf` 第 6 页有一句话概括了电控到底在干什么，找到它。

**验收标准**

- [ ] 现场演示：用手机蓝牙 App 让舵机转到 3 个指定角度、电机正反转
- [ ] 画出你的**帧结构图**，并说明每个字段在防什么
- [ ] 故意发坏数据时程序**不失控**（不乱动、不跑飞），能自己恢复
- [ ] 能答出"中断里该做多少事"，并举一个自己踩过的反例

### 任务 3｜运动学解算：蓝牙发目标速度，四个电机一起动

**两种轮形都要做**：全向轮（45° 四角）和麦克纳姆轮。

**做什么**

| 步 | 任务 |
|---|---|
| 1 | 蓝牙发来 `vx, vy, ω` 三个目标量 |
| 2 | 用运动学公式解算成四个轮子的目标速度 |
| 3 | 下发给四个电机 |
| 4 | **把车架起来（悬空）**验证：前后 / 左右 / 原地转，三个方向都对 |

> ⚠️ **现实情况：你们手上的电机是开环的**（没有编码器反馈、也没有带闭环的电调）。
> 所以第 3 步"下发给电机"其实是**给占空比**，不是给速度。
> 你只能先按经验给一个"速度 → 占空比"的系数凑合 —— 这个系数准不准、靠不靠得住，就是**任务 5** 要测的事。

**核心掌握（按顺序答，别跳）**

1. **为什么四个轮子的公式长得不一样？** 逐个说出每个轮子那几项**符号的来历**。
   > 对照：`5.1-麦轮运动学解算.md` 第三节、`5.2-全向轮运动学解算.md` 第三节。
   > 注意：**5.1 和 5.2 的 `vy` 正方向不一样**，别混。
2. **把受力讲出来**：麦轮的辊子是 45° 的，它"出力"的方向是斜的 ——
   - 沿辊子方向为什么几乎不打滑？
   - 垂直方向为什么能自由滑过去？
   - **原地自转**时，四个轮子受的地面摩擦力方向分别朝哪？
3. **限幅**：`vx = 10 m/s` 时你算出的轮速是 30 m/s，但车根本没有这个速度 —— 你怎么办？
   > 提示：是"每个轮子各自削顶"，还是"整体等比缩放"？
   > 两种做法分别会破坏什么？（想一想"车本来想直线走，削顶之后会怎样"）

**验收标准**

- [ ] 现场推导任一轮子的公式（**不许看讲义**）
- [ ] 悬空测试：前进 / 后退 / 左移 / 右移 / 原地左转 / 原地右转，**六个方向都对**
- [ ] 能说清"限幅为什么要整体等比缩放"
- [ ] 两种轮形的公式都推过（麦轮 + 全向轮）

### 任务 4｜机械臂：多个舵机配合，让末端到指定位置

底盘那条链是"目标速度 → 轮速"；机械臂这条链是"**目标位姿 → 各个舵机角度**" —— **逆运动学**。

| 4 | 让末端走到几个指定点，**实测位置**，和计算的对比 |

**核心掌握（按顺序答，别跳）**

### 任务 5｜开环能开出"速度"吗？—— 标定「占空比 ↔ 转速」

> 这一项**不需要编码器**，你手上的开环电机就能做。
> 它要回答一个问题：**没有反馈，我能不能让车轮准确地转？**

**做什么**

| 步 | 任务 |
|---|---|
| 1 | 电机空载，占空比从 0 一点点加到 100%，记下每个占空比对应的**实际转速**（转速表 / 手机慢动作 / 数圈计时） |
| 2 | 画成曲线：占空比（x）→ 转速（y） |
| 3 | 加**负载**（手轻轻压轮子），再测一遍 —— 曲线还是同一条吗？ |
| 4 | 换一块**电压不同**的电池（比如满电 12.6 V vs 11 V），再测一遍 |

**核心掌握（按顺序答，别跳）**

1. **死区**：为什么占空比从 0 加到某个值之前，电机根本不转？你的电机"最低占空比"大概是多少？
2. **加了负载之后，同一个占空比对应的转速变了吗？**
   这说明占空比控制的到底是什么？
   > 提示：占空比控制的其实是电机的**平均电压**。
   > 从电压到转速，中间还隔着什么？（电流？负载转矩？）
3. **电池电压掉下去之后转速也跟着掉，为什么？**
4. **关键的一问**：如果我要车"稳稳地走 1 m/s"，靠占空比可靠吗？**那我缺的是什么？**
   > 提示：你现在只管"给出去多少"，并不知道"轮子实际转多快"。
   > 对比一下：舵机为什么能准确地转到 90°？（它里面有什么？）

**验收标准**

- [ ] 一张"占空比 ↔ 转速"曲线图，**空载 + 负载两条线画在同一张图上**
- [ ] 能说出死区为什么存在，以及你电机的最低占空比
- [ ] 能举出**至少两个**"开环不靠谱"的具体场景（不许只答"负载会变"）
- [ ] 能回答"要准确控制速度，我还缺什么" —— 用自己的话，不许背

### 任务 7｜闭环：编码器 + 速度环 PID（等硬件到位再做）

> ⚠️ **为什么放到最后？**
> 因为你们手上的电机**现在是开环的** —— 指令发下去就完事，电机实际转多快你不知道
> （任务 5 已经让你亲手体会过这件事了）。**没有反馈，PID 无从谈起。**
> 所以这一项**先看懂，别急着做** —— 等有编码器 / 闭环电调了，再回来做。
>
> 讲义：`5-控制算法/PID/5.4-PID控制器.md`

**做什么**

| 步 | 任务 |
|---|---|
| 1 | 读编码器，把脉冲数换算成**真实转速**（m/s 或 RPM） |
| 2 | 只开 P，调到满意，记录 `Kp` 和现象 |
| 3 | 加 I，把稳态误差磨掉，记录现象 |
| 4 | （可选）加 D，并给反馈做低通滤波 |
| 5 | 用 Ozone / 上位机把"目标 / 实际 / 输出"**三条曲线**画出来 |

**核心掌握（按顺序答，别跳）**

1. **P 是"现在"、I 是"过去"、D 是"未来"** —— 用你自己的数据，各举一个现象来证明这句话。
2. **为什么只有加上 I 才能消掉稳态误差？** 只用 P 的时候误差为什么磨不掉？
3. **积分饱和**：让目标突然变得很大，观察输出卡在限幅值上不下来 —— 这就是 windup。你会怎么防？
4. **`dt` 必须是稳定的常数**：把调用周期从 1 ms 改成 20 ms、**参数不重调**，会发生什么？为什么？
5. **微分先行**：稳态时目标从 1.0 突然跳到 3.0，
   `d = (err - err_last)/dt` 和 `d = -(actual - actual_last)/dt` 算出来的 D 项差多少？
   > 动手算一遍，别只看结论。
6. **回头对照任务 5**：装上这个环之后，任务 5 里那几条"开环不靠谱"的场景，分别被解决了没有？

**验收标准**

- [ ] 三条曲线截图（目标 / 实际 / 输出），标出超调量、上升时间、稳态误差
- [ ] 能解释"我为什么这么调" —— 每一步的动机，不是背口诀
- [ ] 现场演示积分饱和，并说出你用什么办法防的
- [ ] 能说出 `dt` 不稳会造成什么
- [ ] 能回答"任务 5 的那几条开环问题，闭环解决了哪几个"
