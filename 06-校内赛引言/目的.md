# 本章主要是辅助 理解 一个简单的系统，电控的思路
讲解一辆校内赛小车需要实现什么样的功能，该以怎么的思路来实现自己的功能
1. 分析系统组成 底盘 ，控制核心，遥控 （机械臂）.....
2. 这些模块需要什么材料 （电机，舵机，蓝牙驱动模块，单片机.....）
3. 将这些功能与培训的内容相关联
4. 代码得到规范，与逻辑的优化，github的代码上传+
