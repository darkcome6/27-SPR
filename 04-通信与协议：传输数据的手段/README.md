# 05 · 通信与协议：传输数据的手段
协议只是数据通讯的手段，所有的协议抽象过后大同小异，发送目标，数据，校验，本身对应控制没有太大意义，实际应用过程都是以迁移项目为主要开发流程，SPI IIC 等不常用的手段，了解即可，主要精力投入USART协议 CAN协议
## 课程清单
# 基础
1. 介绍USART口的基本原理
2. 围绕实现蓝牙遥控，来讲解一个USART项目的实现
3. 让新生理解到协议机制是固定的但是协议传输的数据的每一位的意义都是自己通讯的双方来敲定的（自瞄/导航）
4. 缓存区的意义？为什么所有的协议数据量一上来都会使用缓存区
--- 
# 进阶
5. 双DMA缓存区的机制（不注重函数，机制的理解，数据的流转始终是我们忘掉语法糖之后剩下来的东西）
6. 围绕 自瞄的云台角度 串口部分的解包 流程 进行讲解
7. CAN 通讯的基本原理 一帧数据的构成
8. 常见的 CAN总线的布线 标准串行总线 星形线 终端电阻
9. CAN信号的基本配置，从时钟总线，到过滤器，到发送函数，接受函数，按照队里日常使用的程度来讲
