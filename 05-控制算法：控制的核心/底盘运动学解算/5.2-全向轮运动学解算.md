# 5.2 全向轮的运动学解算

> **一句话本质：全向轮"沿轮面方向能驱动，垂直方向自由滑"。**
> 所以它的解算，本质就是**把车体想要的速度，投影到每个轮子的驱动方向上去**。

---

## 一、先看清全向轮和麦轮的区别

| | 麦轮 | 全向轮 |
|---|---|---|
| 辊子方向 | 与轮轴成 **45°** | 与轮轴**平行**（垂直于轮面方向） |
| 能力 | 滚动方向出力 **+ 45° 斜着出力** | 滚动方向出力，**垂直方向自由滑** |
| 典型布局 | 四轮 90° 分布 | 三轮 120°、四轮 90°、四轮 45° |
| 常见用途 | 底盘平移 | 三轮小底盘、以及"布局不同"的各种全向底盘 |

**关键差别**：麦轮的辊子是斜的，所以它"出的力也是斜的"；全向轮辊子与轮面平行，它**只在轮面方向上出力**，垂直于轮面的方向全靠辊子滑过去。

---

## 二、通用解算公式（这一节最值钱的东西）

**先定坐标系**（本节跟实车代码一致，**和 5.1 不同**，见例 3 的对照）：

| 量 | 约定 |
|---|---|
| `x` | 车头朝前为正 |
| `y` | **车体向右为正** |
| `ω` | **俯视逆时针（左转）为正** |

**结论：任何一个全向轮布局，都能用这一个式子算出来。**

每个轮子只要知道两件事：**装在哪**（轮心坐标 `(x_i, y_i)`）、**朝哪个方向出力**（驱动方向单位矢量 $\hat d_i$，在"前 x、右 y"坐标系里写出）：

$$
v_i = \hat d_i \cdot \big[\,(v_x,\,v_y) \;+\; \omega\,(y_i,\,-x_i)\,\big]
$$

**等价的"角度形式"**（用角度写，和上面是同一个东西）：

$$
v_i = v_x\sin(\alpha_i+\beta_i) - v_y\cos(\alpha_i+\beta_i) + l_i\cos(\beta_i)\,\omega
$$

> ⚠️ 这里 `α`、`β` 都是**顺时针为正**的（因为 y 轴朝右）。
> 5.1（麦轮）用 y 左、逆时针为正，所以公式长相不同 —— **不是谁算错了，是坐标系换了。**

| 符号 | 含义 |
|---|---|
| `v_i` | 第 i 个轮的**线速度**（m/s，正 = 沿它的驱动正方向） |
| `α_i` | 第 i 个轮**所在位置的方位角**（车体中心 → 轮心，从 x 轴起算，**顺时针为正**） |
| `β_i` | 第 i 个轮的**驱动方向相对切向的偏角**（0 = 沿切向驱动，顺时针为正） |
| `l_i` | 轮心到车体中心的距离 |
| `vx, vy, ω` | 车体前后 / 左右 / 偏航角速度（**x 前、y 右**、ω 逆时针为正） |

**这个式子在干什么？**
1. 第一项 `(v_x, v_y)`：车体平移速度。把它 `(vx, vy)` **投影**到轮子的驱动方向 `d̂ᵢ` 上 —— 只有这个方向上的分量需要轮子去"跑"。
2. 第二项 `ω·(y_i, −x_i)`：车体自转时**轮心处**多出来的那部分线速度。
   > 符号好记：右侧的轮子（y > 0），左转时往前走。

> **推导一次，受用很久**：换布局只改两样东西 —— **轮心坐标 `(x_i, y_i)`** 和 **驱动方向 $\hat d_i$**，公式本身一个字不用动。
> （这就是为什么下面三个例子都不用重新推，只是把 `(x_i, y_i)` 和 $\hat d_i$ 换一换。）

## 三、三个最常见的例子

### 例 1：三轮全向（120° 均布，切向驱动，β = 0）

三个轮分别在 `α = 0° / 120° / 240°`，`l` 相同，代入通用式：

$$
\begin{aligned}
v_1 &= -v_y + l\,\omega\\
v_2 &= -0.866\,v_x + 0.5\,v_y + l\,\omega\\
v_3 &= +0.866\,v_x + 0.5\,v_y + l\,\omega
\end{aligned}
$$

**从这组式子能看到三件有用的事：**

1. **前后走**（`vx`）靠的是 2 号、3 号轮（1 号轮在正前方，切向驱动，帮不上前后）。
2. **左右平移**（`vy`）三个轮都参与。
3. **自转**（`ω`）—— **三个轮全部同向同速**（都是 `+lω`）。
   这跟麦轮/坦克的"左右两侧反向"完全不同，**是三轮全向最容易被搞错的地方**。

### 例 2：四轮全向（90° 均布，切向驱动，β = 0）

`α = 0° / 90° / 180° / 270°`：

$$
v_{\text{前}} = -v_y + l\omega,\quad
v_{\text{左}} = -v_x + l\omega,\quad
v_{\text{后}} = +v_y + l\omega,\quad
v_{\text{右}} = v_x + l\omega
$$

也就是"**前后两个轮管平移，左右两个轮管前后**"——布局换了，职责就换了。
（同一台车如果用 45° 布局，就退化成了"麦轮式"的解算，只是没有 45° 辊子带来的额外系数。）

### 例 3：四轮 45°（切向驱动）—— 全向底盘用得最多的布局

四个轮子在**四个角**，每个轮子**沿切向驱动**（驱动方向垂直于它到中心的连线）。
这就是常见的"X 型"全向底盘，也是那份推导 PDF 里推的那个。

**按通用公式，把四个轮子的位置和驱动方向写出来**（前 x、右 y）：

| 轮 | 轮心位置 `(x_i, y_i)` | 驱动方向 $\hat d_i$ |
|---|---|---|
| 0 前左 | `(+√2/2, −√2/2)·l` | `(−√2/2, −√2/2)` |
| 1 前右 | `(+√2/2, +√2/2)·l` | `(+√2/2, −√2/2)` |
| 2 后右 | `(−√2/2, +√2/2)·l` | `(+√2/2, +√2/2)` |
| 3 后左 | `(−√2/2, −√2/2)·l` | `(−√2/2, +√2/2)` |

代入后得到（记 `A = lω`）：

$$
\begin{aligned}
v_0 &= -\tfrac{\sqrt2}{2}v_x - \tfrac{\sqrt2}{2}v_y + A\\
v_1 &= +\tfrac{\sqrt2}{2}v_x - \tfrac{\sqrt2}{2}v_y + A\\
v_2 &= +\tfrac{\sqrt2}{2}v_x + \tfrac{\sqrt2}{2}v_y + A\\
v_3 &= -\tfrac{\sqrt2}{2}v_x + \tfrac{\sqrt2}{2}v_y + A
\end{aligned}
$$

**最值得注意的一点：`ω` 那一项，四个轮子全是 `+A`，方向完全一样。**

这不是抄错 —— **这个布局的自转本来就要求四个轮子同向同速**：每个轮子的驱动方向都垂直于它到中心的连线，车一绕中心转，四个轮子自然都沿自己的驱动方向往同一个转向滚。

> 对照一下：**三轮 120° 也是"自转时全同向"**，而**麦轮 / 坦克是"左右两侧反向"**。
> 三类布局三种行为，别混。

### ⚠️ 和 5.1（麦轮）不一致的地方：`vy` 的正方向

| | 5.1 麦轮 | 5.2 全向（本节） |
|---|---|---|
| `vy` 正方向 | **向左** | **向右** |

两个都行，但**混用就是符号错误**。本节用"向右为正"，是因为要**和实车代码一致**（代码就在下面）。
换算关系：`vy(向右) = −vy(向左)`。

> **5.3（舵轮）也用的是"向右为正"**，所以 5.2 和 5.3 之间可以直接对照，只有 5.1 要换号。

### 对照实车代码

```c
wheel_speed[0] = ( SQRT2 * vy_set + SQRT2 * vx_set - MOTOR_DISTANCE_TO_CENTER * wz_set);
wheel_speed[1] = ( SQRT2 * vy_set - SQRT2 * vx_set - MOTOR_DISTANCE_TO_CENTER * wz_set);
wheel_speed[2] = (-SQRT2 * vy_set - SQRT2 * vx_set - MOTOR_DISTANCE_TO_CENTER * wz_set);
wheel_speed[3] = (-SQRT2 * vy_set + SQRT2 * vx_set - MOTOR_DISTANCE_TO_CENTER * wz_set);
```

把代码里 `vx` / `vy` 的系数和上面的公式对一遍（比如 `w0 = √2(vx + vy)`，而 `v_0 = −(√2/2)(vx + vy)`），会发现：

> **代码 = 上面公式 ×（−2）** —— 只有**整体取负 + 缩放**，没有给某个轮单独反号。

**为什么要整体取负**：`v_i` 的正方向是"沿驱动方向的物理滚动方向"，而**电机给正电流时的实际转向与它相反**（推导 PDF 第 5 页写的就是这件事）。

> ⚠️ 这点和 5.1（麦轮）**不一样**：麦轮代码里是"右侧两个轮单独反号"。
> **两个底盘的约定不同，不要互相套。**

## 四、正解与"能不能推出来"

三个轮 → 三个方程 → 正好解出 `(vx, vy, ω)`：


```c
/* 三轮全向（β=0，120° 均布）正解 */
float s = sinf(2.0f * PI / 3.0f);     /* sin120° = 0.866 */
vx = (v[2] - v[1]) / (2.0f * s);
vy = -(2.0f * v[0] - v[1] - v[2]) / 3.0f;   /* 注意前面的负号：本节 vy 向右为正 */
w  = (v[0] + v[1] + v[2]) / (3.0f * l);
```

**三步自查**（和 5.1 一样的手法，用来验证你的公式）：

| 指令 | 应该看到 |
|---|---|
| 只有 `vy > 0` | `v1 > 0`（正前方轮向右……按你的布局推），三个轮都参与 |
| 只有 `ω > 0` | **三个轮同向同速** |
| 只有 `vx > 0` | 1 号轮不动 / 不参与（切向驱动，帮不上前后） |

> 若你的实车不是"三个轮同向同速"地自转，那**不是公式错，就是某个轮装反了**——先架空测试。

## 五、常见坑

1. **`α` 和 `β` 的参考方向没写清楚** → 换个人接手，符号全错。**必须把定义写进代码注释**。
2. **把三轮全向的自转当成麦轮**（以为要左右反向）→ 自转直接变成"平移+打滑"。
3. **三轮全向的"不可驱动方向"**：某些方向下三个轮会互相顶（矩阵接近奇异）→ 表现为"某个方向特别难走/特别慢"。选布局时要避开。
4. **轮子装反一个** → 车会"一边走一边转"，且不同方向的表现完全不同（很难靠感觉猜，必须架空逐轮验证）。
5. **没做限幅**：和 5.1 一样，必须**整体缩放**，别单独裁某个轮。
6. **`l` 用错**：是"轮心到**车体旋转中心**"的距离，不是到几何外接圆的距离。
