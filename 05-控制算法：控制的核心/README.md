# 06 · 控制算法：

> **控制才是一个电控的核心能力——苦苦调参，不如好好优化控制器。**

这一章不教"抄一套参数"，而是让你明白：**每一个输出量是怎么算出来的、为什么这么算。**
把控制器和运动学想清楚了，调参只是最后那一层薄薄的功夫。

## 本章要回答的核心问题

- 遥控杆动一下，四个轮子各自该转多快？——**运动学解算**
- 轮子转多快才叫"调到 1 m/s"？——**闭环控制器**
- 为什么同样的 PID，别人调得又快又稳，我的又抖又慢？——**结构（串级/前馈/补偿）比参数更重要**
- 云台指着前方，底盘却转了 30°，速度该怎么算？——**坐标变换**

> **按顺序学**：先把运动学跑通（轮子听你的话），再上控制器（速度/角度闭环），最后才是前馈、补偿、坐标变换这些"让它更好"的东西。
> 跳过前两步直接抄 PID 参数，就是"苦苦调参"的根源。

## 学习方式

1. **公式要能讲出来**：不只记 `v_FL = vx - vy - kω`，要能说出每一项**为什么出现在那里**。
2. **每个结论都上实车验证**：架空测试、推车测试、阶跃响应——**控制这一章没有"我觉得对"**。
3. **先看波形再调参数**：没有波形（Ozone / 上位机曲线）的调参等于闭眼开车。

## 通用约定（本章所有公式都用这套）

- 车体坐标系：**x 向前，y 向左**（右手系，z 向上）
- **逆时针为正**：偏航角 ψ、角速度 ω（俯视看，逆时针是正方向）
- 角度计算统一用**弧度**，只有人机交互时才转成度
- 速度单位统一 **m/s**，轮子用 **rad/s**，两者靠轮半径 R 换算：`v = ω·R`
