# 5.1 麦轮的运动学解算（X 型 / O 型）

> **一句话本质：麦轮的辊子与轮轴成 45°，它"出力"的方向是斜的。**
> 四个斜着出力的轮子一配合，就能让底盘前后走、左右平移、原地自转——**解算就是把"我想怎么走"翻译成"四个轮子各转多快"。**

---

## 一、先搞清楚麦轮特殊在哪

普通轮子只能沿轮子转的方向出力；麦轮在轮圈上装了一圈 **45° 的辊子**：

- 沿轮子的滚动方向 → **能主动出力**（和普通轮子一样）
- 垂直于滚动方向 → **辊子自由转动，几乎不打滑地向侧向滑**

一个轮子，同时具备"驱动"和"侧滑"两种能力 —— 这就是它能全向移动的原因。

> 换个角度看：辊子 45°，意味着**轮子出的力也是 45° 斜着的**。
> 四个轮的斜力矢量合成，就决定了底盘的运动方向。

---

## 二、符号约定（很重要，先立规矩）

本章统一用下面这套约定，**写代码前先把注释抄进文件头**：

| 符号 | 含义 |
|---|---|
| `vx` | 车体前后速度，**向前为正**（m/s） |
| `vy` | 车体左右速度，**向左为正**（m/s） |
| `ω` | 偏航角速度，**俯视逆时针为正**（rad/s） |
| `l_x` | 半轴距 = 前后轮中心距 ÷ 2（m） |
| `l_y` | 半轮距 = 左右轮中心距 ÷ 2（m） |
| `k` | `l_x + l_y`（角速度项的力臂） |
| `v_FL / v_FR / v_BL / v_BR` | 左前 / 右前 / 左后 / 右后轮的**线速度**（m/s） |

---

## 三、反解：遥控值 → 四个轮速

**这是底盘代码里最常用的一组公式。**

$$
\begin{aligned}
v_{FL} &= v_x - v_y - k\,\omega\\
v_{FR} &= v_x + v_y + k\,\omega\\
v_{BL} &= v_x + v_y - k\,\omega\\
v_{BR} &= v_x - v_y + k\,\omega
\end{aligned}
$$

**别背，要能看懂每一项：**

| 项 | 谁贡献的 | 怎么理解 |
|---|---|---|
| `vx` | 前后 | 四个轮同向同速 → 车往前走 |
| `±vy` | 平移 | **对角**的两个轮反向：左前、右后一组，右前、左后一组 |
| `±kω` | 自转 | **左、右两侧**反向：和坦克一样，左侧倒转、右侧正转 → 车原地转 |

用三个特例自查（**这是验证公式的最快办法**）：

| 指令 | 轮子表现 | 对不对 |
|---|---|---|
| 只有 `vx > 0` | 四轮同向同速 | 前进 ✅ |
| 只有 `vy > 0`（向左平移） | 左前、右后 **倒转**；右前、左后 **正转** | 对角同向 ✅ |
| 只有 `ω > 0`（俯视逆时针） | 左侧两轮**倒转**、右侧两轮**正转** | 坦克式自转 ✅ |

---

## 四、正解：轮速 → 车体速度（里程计）

反过来解同一个方程组：

$$
v_x=\frac{v_{FL}+v_{FR}+v_{BL}+v_{BR}}{4},\quad
v_y=\frac{-v_{FL}+v_{FR}+v_{BL}-v_{BR}}{4},\quad
\omega=\frac{-v_{FL}+v_{FR}-v_{BL}+v_{BR}}{4k}
$$

用途：**里程计定位**、判断"车实际按我想的方向走了吗"。
`ω` 的式子要除以 `4k`：因为轮子离旋转中心越远（`k` 越大），同样的角速度需要更大的线速度。

---

## 五、从"线速度"到"电机转速"

公式算出来的是轮子的**线速度 m/s**，电机要的是转速：

$$
\omega_{\text{wheel}} = \frac{v}{R}\ (\text{rad/s})
\;\Longrightarrow\;
\text{RPM} = \frac{v}{R}\cdot\frac{60}{2\pi}
\;\Longrightarrow\;
\text{电机 RPM} = \text{轮子 RPM} \times \text{减速比}\times g
$$

（`g` 是"有效系数"，见下面第七节，先按 1 算，标定后再修。）

**这里最容易出错的三件事**：轮径量错（要用滚动半径，不是几何半径）、忘了减速比、单位混用（RPM 和 m/s 混着传参）。

---

## 六、X 型 / O 型：到底差在哪

麦轮的辊子有**左右两种旋向（镜像的一对）**，装法不同就出现 X 型 / O 型两种叫法。

**判据（别背名字，看辊子方向）：**

| 布置 | 辊子方向的关系 | 结果 |
|---|---|---|
| ✅ 标准装法（常叫 **X 型**） | **对角线**上两个轮子的辊子方向 **相同**；相邻两轮 **镜像** | 前后 + 平移 + 自转 全都能做 |
| ⚠️ 另一种（常叫 **O 型**） | **相邻**两个轮子的辊子方向 **相同** | 通常表现为平移/自转"不对劲" |

> ⚠️ **存疑提醒**：不同厂商、不同教程对 X / O 的叫法**并不统一**（有的说"X 型辊子轴线俯视呈 X"，有的说"O 型才是 X 的镜像"）。
> 所以——**不要去对名字，去做下面这个实验。**

### 判断实测流程（10 分钟搞定）

1. **把车架空**，让四个轮子离地（或者直接看轮子的辊子方向）。
2. 指令 `vx = 0, vy = +1, ω = 0`（要求向左平移）。
3. 观察四个轮子：
   - **对角同向**（左前与右后同向，右前与左后同向）→ 这是能全向移动的标准装法，用第三节的公式。
   - **同侧同向**（左前与右前同向）→ 辊子装法与公式不匹配，要么轮子装错，要么需要对公式改符号。
4. 指令 `vx = 0, vy = 0, ω = +1`（要求俯视逆时针自转）：
   - 左侧两轮倒转、右侧两轮正转 → 自转定义正确 ✅
   - 若整体反了 → `ω` 的符号取反。

**如果车实际走向和我想要的方向相反，只改对应那一项的符号，别乱改公式结构。**

## 七、实车校准（做完这一步，公式才算真正跑通）

| 步骤 | 做法 | 判据 |
|---|---|---|
| ① 单轮方向 | 逐个轮子给正速度，看轮子真实转向、编码器读数是否**同号** | 驱动与反馈同号 |
| ② 前进 | 给 `vx = +0.5 m/s` 指令 | 车往前走 |
| ③ 平移 | 给 `vy = +0.5 m/s` | 车向左走（不是向右、不是走斜线） |
| ④ 自转 | 给 `ω = +1 rad/s` | 俯视逆时针 |
| ⑤ 速度标定 | 让车以 0.5 m/s 直线走 2 m，量实际耗时 | 实测 ≈ 指令（差得多就调有效系数 `g`） |
| ⑥ 里程计 | 手推车走 1 m，比较里程计增量 | 误差 < 5% 才算能用 |

**麦轮的打滑是"物理定律级"的**：辊子本身就是靠微小滑动工作的，所以里程计一定有误差。
关键不是"消除误差"，而是**知道它大概多大、靠哪些传感器补**（IMU、视觉）。

## 八、别忘了限幅（否则一定撞车）

`vx`、`vy`、`ω` 同时给满时，算出来的轮速会超过电机上限。**必须按比例整体缩放，不能单独裁掉某一个轮**——单独裁会让车"走形"。

```c
#define WHEEL_V_MAX 3.0f        /* m/s，按电机与轮径算出来的上限 */
#define MOTOR_NUM   4

/* 先算四个轮速（反解） */
Mecanum_Solve(vx, vy, w, v);    /* v[] 里是 4 个轮子的目标线速度 */

/* 再按"最大者优先"整体缩放 */
float max = 0.0f;
for (uint8_t i = 0; i < MOTOR_NUM; i++) {
    float a = fabsf(v[i]);
    if (a > max) max = a;
}
if (max > WHEEL_V_MAX) {
    float scale = WHEEL_V_MAX / max;
    for (uint8_t i = 0; i < MOTOR_NUM; i++) {
        v[i] *= scale;           /* 整体缩放：方向不变，速度等比降低 */
    }
}
```

## 九、常见坑

1. **轮径 / 减速比填错** → 车"跑得比指令快一倍"或"像蜗牛"（现象很像 PID 不行，其实是单位错）。
2. **`vy` 符号反了** → 平移方向反；打舵时车会"画圈"。
3. **`ω` 的力臂写成 `l_x` 或 `l_y`** → 自转速度不对；正确是 `l_x + l_y`。
4. **没做整体缩放限幅** → 斜着走时某个轮子先到上限，车走成曲线。
5. **编码器方向与驱动方向不一致** → 速度环一上电就"飞"（正反馈）。
6. **X/O 装错或四个轮子只用一种旋向** → 平移时四个轮互相顶，原地打滑、磨损加剧。
7. **指望里程计长时间准** → 麦轮打滑 + 辊子磨损，长时间一定漂，要靠别的传感器融合。
