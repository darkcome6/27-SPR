# 5.9.1 纯陀螺仪积分：角速度如何变成姿态

## 本章目标

先只使用陀螺仪，把三轴角速度积分成 roll、pitch、yaw。完成后应能观察到：短时间内姿态跟手，但静止放置一段时间后，角度会因零偏和噪声逐渐漂移。

## 输入和约定

- `gx, gy, gz`：机体系三轴角速度，单位 **rad/s**。
- `dt`：本次采样与上次采样的时间间隔，单位 **s**。
- 姿态角以弧度保存，采用右手系。
- 加速度计读数暂不参与计算。

> 若陀螺仪输出为 `deg/s`，先乘 `π/180` 转成 `rad/s`。不要把 `ms` 当成 `s` 使用。

## 姿态角积分

三维姿态使用欧拉角时，机体系角速度一般不等于 roll、pitch、yaw 各自的变化率。对 Z-Y-X（yaw-pitch-roll）欧拉角，角度变化率为：

$$
\begin{aligned}
\dot\phi &= g_x+\sin\phi\tan\theta\,g_y+\cos\phi\tan\theta\,g_z\\
\dot\theta &= \cos\phi\,g_y-\sin\phi\,g_z\\
\dot\psi &= \frac{\sin\phi}{\cos\theta}g_y+
            \frac{\cos\phi}{\cos\theta}g_z
\end{aligned}
$$

其中 `φ`、`θ`、`ψ` 分别是 roll、pitch、yaw。用显式欧拉法离散积分：

$$
\text{angle}_{k+1}=\text{angle}_k+\dot{\text{angle}}\,dt
$$

```c
#include <math.h>
#include <stdbool.h>
#include <stddef.h>

typedef struct {
    float roll;   /* rad */
    float pitch;  /* rad */
    float yaw;    /* rad */
} GyroEuler;

bool GyroIntegrateEuler(GyroEuler *attitude,
                        float gx, float gy, float gz, /* rad/s */
                        float dt)                     /* s */
{
    if (attitude == NULL || dt <= 0.0f) {
        return false;
    }

    const float roll = attitude->roll;
    const float pitch = attitude->pitch;
    const float sin_roll = sinf(roll);
    const float cos_roll = cosf(roll);
    const float cos_pitch = cosf(pitch);

    /* 欧拉角在 pitch = +/-90 deg 附近存在奇异性。 */
    if (fabsf(cos_pitch) < 1e-3f) {
        return false;
    }

    const float tan_pitch = tanf(pitch);
    const float roll_rate =
        gx + sin_roll * tan_pitch * gy + cos_roll * tan_pitch * gz;
    const float pitch_rate = cos_roll * gy - sin_roll * gz;
    const float yaw_rate =
        (sin_roll * gy + cos_roll * gz) / cos_pitch;

    attitude->roll += roll_rate * dt;
    attitude->pitch += pitch_rate * dt;
    attitude->yaw += yaw_rate * dt;
    return true;
}
```

## 怎么验证

1. 保持 IMU 静止，观察三轴角度是否缓慢变化。
2. 绕一个轴缓慢旋转，再停下；观察积分角是否大致跟随实际转角。
3. 改变 `dt` 的单位或陀螺仪单位，观察错误的量纲会怎样破坏结果。

## 这一阶段的结论

- 积分能跟踪快速变化，但陀螺仪零偏也会被积分，误差随时间累积。
- `yaw` 同样会漂移；没有外部航向参考时，单靠陀螺仪无法长期固定航向。
- 欧拉角在 pitch 接近 ±90° 时会奇异。完整三维姿态系统通常用四元数积分；本函数用于先理解“角速度积分”的基本问题。
- 上电静止时可以估计陀螺仪零偏并在积分前扣除，但标定不能消除温漂和后续噪声。
