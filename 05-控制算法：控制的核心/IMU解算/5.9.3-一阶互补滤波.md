# 5.9.3 一阶互补滤波：融合陀螺仪和加速度计

## 本章目标

将陀螺仪积分的快速姿态变化与加速度计提供的 roll / pitch 长期参考融合起来。先实现固定时间常数的一阶互补滤波，再观察固定信任比例在运动干扰下的局限。

## 融合公式

以 roll 为例，先用陀螺仪预测当前角度，再用加速度计倾角校正：

$$
\begin{aligned}
\phi_g(k)&=\phi(k-1)+\dot\phi_g\,dt\\
\phi(k)&=\alpha\phi_g(k)+(1-\alpha)\phi_a(k)
\end{aligned}
$$

pitch 同理。`α` 越接近 1，越信任陀螺仪；越接近 0，越信任加速度计。下面用时间常数 `τ` 计算离散系数：

$$
\alpha=\frac{\tau}{\tau+dt}
$$

固定 `τ` 比直接写死一个 `α` 更容易跨采样周期理解，但它仍然是固定的频率折中，并不会自动判断加速度计此刻是否受到运动干扰。

## C 函数

输入角速度为 `rad/s`、采样间隔为 `s`；加速度计单位可为 `g` 或 `m/s²`，但水平静止时需符合本系列章节的正 z 约定。`tau` 单位为秒。

```c
#include <math.h>
#include <stdbool.h>
#include <stddef.h>

typedef struct {
    float roll;   /* rad */
    float pitch;  /* rad */
    float yaw;    /* rad；仅陀螺积分，长期会漂 */
    float tau;    /* s；固定时间常数 */
} ComplementaryFilter;

static float WrapPi(float angle)
{
    const float two_pi = 6.28318530718f;
    while (angle > 3.14159265359f) {
        angle -= two_pi;
    }
    while (angle < -3.14159265359f) {
        angle += two_pi;
    }
    return angle;
}

bool ComplementaryUpdate(ComplementaryFilter *filter,
                         float gx, float gy, float gz, /* rad/s */
                         float ax, float ay, float az,
                         float dt)                     /* s */
{
    if (filter == NULL || dt <= 0.0f || filter->tau <= 0.0f) {
        return false;
    }

    const float accel_norm_sq = ax * ax + ay * ay + az * az;
    if (accel_norm_sq < 1e-12f) {
        return false;
    }

    const float roll = filter->roll;
    const float pitch = filter->pitch;
    const float sin_roll = sinf(roll);
    const float cos_roll = cosf(roll);
    const float cos_pitch = cosf(pitch);
    if (fabsf(cos_pitch) < 1e-3f) {
        return false;
    }

    const float tan_pitch = sinf(pitch) / cos_pitch;
    const float roll_rate =
        gx + sin_roll * tan_pitch * gy + cos_roll * tan_pitch * gz;
    const float pitch_rate = cos_roll * gy - sin_roll * gz;
    const float yaw_rate =
        (sin_roll * gy + cos_roll * gz) / cos_pitch;

    const float roll_pred = roll + roll_rate * dt;
    const float pitch_pred = pitch + pitch_rate * dt;
    const float accel_roll = atan2f(ay, az);
    const float accel_pitch = atan2f(-ax, sqrtf(ay * ay + az * az));
    const float alpha = filter->tau / (filter->tau + dt);

    /* 取最短角差，避免跨越 +/-pi 时线性混合跳变。 */
    filter->roll = WrapPi(
        roll_pred + (1.0f - alpha) * WrapPi(accel_roll - roll_pred));
    filter->pitch = WrapPi(
        pitch_pred + (1.0f - alpha) * WrapPi(accel_pitch - pitch_pred));
    filter->yaw += yaw_rate * dt;
    return true;
}
```

## 使用与观察

- 初始化时设定 `filter.roll`、`filter.pitch`、`filter.yaw`；可用静置加速度计结果初始化 roll / pitch，yaw 初值设为零。
- `tau` 可从约 `0.5 s` 开始试验，再按静态收敛速度、运动时倾角抖动进行调整。
- 运动加速时，固定 `tau` 仍会按原比例融合加速度计倾角，可能把姿态拉偏。
- `yaw` 没有加速度计校正，仍会漂移。

## 这一阶段的结论

一阶互补滤波将陀螺仪的快速响应和加速度计的重力参考结合起来，但固定权重无法根据传感器当前质量调整信任程度。下一阶段使用 Mahony 的姿态误差反馈，并可额外根据加速度模长动态调整校正强度。
