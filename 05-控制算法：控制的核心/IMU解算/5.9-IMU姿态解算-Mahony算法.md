# 5.9 传感器数据的算法处理：Mahony 姿态解算

> **一句话本质：陀螺仪准在"短时间"，加速度计准在"长时间"。**
> Mahony 算法就是让加速度计**持续把陀螺仪积分出来的漂移"拉回来"**。

---

## 一、两个传感器各自的毛病

| 传感器 | 测什么 | 优点 | 致命缺点 |
|---|---|---|---|
| **陀螺仪** | 角速度（deg/s） | 动态响应快、噪声小 | **积分会漂**（零偏 × 时间，一分钟能漂好几度） |
| **加速度计** | 比力（含重力） | 静止时能准确测出**重力方向** | 运动时测到的是"运动加速度 + 重力"的合力；噪声大 |

**所以：一个负责"灵敏"，一个负责"不跑偏"。** 融合 = 互补滤波。

**Mahony 就是一种"用 PI 控制器做互补滤波"的方法**（同类的还有 Madgwick、EKF）。

---

## 二、一个必须知道的事实：**yaw 修不了**

重力方向是**竖直的**。绕竖直轴（yaw）旋转，**重力方向完全不变** —— 所以：

> **加速度计只能修正 roll / pitch，yaw 不可观测。**

后果（非常实际）：

- yaw 只能靠**陀螺积分**，一定会随时间漂移。
- 要么接受漂移并在静止时标定零偏，要么上**磁力计**（易受电机磁场干扰），
  要么用**别的信息源**（云台/底盘的电机机械角度、视觉、激光）。
- **很多人第一次做 IMU 时被这句话坑一整天**："为什么 yaw 一直在慢慢跑？"

---

## 三、Mahony 在干什么（六步）

```
① 陀螺角速度 ω（机体系）
② 用四元数 q 把"世界重力方向"转到机体系 → 预测重力 v̂
③ 加速度计实测重力方向 â（归一化）
④ 误差 e = â × v̂ ── 叉积同时给出"转轴"和"误差大小"
⑤ ω_c = ω + Kp·e + Ki·∫e ── 用 PI 把误差反馈到角速度上
⑥ 用 ω_c 积分四元数，并归一化 → 新的姿态 q
```

**关键公式：**

**② 由四元数预测机体坐标系下的重力方向**（`q = [q0, q1, q2, q3]`，q0 为实部）：

$$
\hat v = \begin{bmatrix}
2(q_1q_3 - q_0q_2)\\
2(q_2q_3 + q_0q_1)\\
q_0^2 - q_1^2 - q_2^2 + q_3^2
\end{bmatrix}
$$

**④ 叉积得到误差**（`â` 是归一化后的加速度计读数）：

$$
e = \hat a \times \hat v
$$

**⑤ PI 修正角速度**：

$$
\omega_c = \omega + K_p\,e + K_i\!\int e\,dt
$$

**⑥ 四元数积分**（`dt` 为固定采样周期）：

$$
\dot q = \tfrac12\, q \otimes (0,\, \omega_c),
\qquad q \leftarrow \frac{q}{\|q\|}
$$

```c
/* Mahony 单步（简化示意，变量含义见上面公式） */
void Mahony_Update(float gx, float gy, float gz,      /* rad/s */
                   float ax, float ay, float az,      /* g，未归一化也行 */
                   float dt)
{
    /* ① 归一化加速度 */
    float norm = sqrtf(ax*ax + ay*ay + az*az);
    if (norm < 1e-6f) return;                  /* 自由落体/异常：直接跳过校正 */
    ax /= norm; ay /= norm; az /= norm;

    /* ② 预测重力方向（这里用 q0..q3 的常见写法） */
    float vx = 2.0f * (q1*q3 - q0*q2);
    float vy = 2.0f * (q2*q3 + q0*q1);
    float vz = q0*q0 - q1*q1 - q2*q2 + q3*q3;

    /* ④ 误差 = â × v̂ */
    float ex = ay*vz - az*vy;
    float ey = az*vx - ax*vz;
    float ez = ax*vy - ay*vx;

    /* ⑤ PI：把误差反馈回角速度（Ki 负责消除陀螺零偏） */
    if (two_ki > 0.0f) {
        exInt += ex * dt; eyInt += ey * dt; ezInt += ez * dt;
        gx += two_kp*ex + two_ki*exInt;
        gy += two_kp*ey + two_ki*eyInt;
        gz += two_kp*ez + two_ki*ezInt;
    } else {
        gx += two_kp*ex; gy += two_kp*ey; gz += two_kp*ez;
    }

    /* ⑥ 四元数积分（先存旧值，避免更新顺序互相影响） */
    float q0o = q0, q1o = q1, q2o = q2, q3o = q3, h = 0.5f * dt;
    q0 += (-q1o*gx - q2o*gy - q3o*gz) * h;
    q1 += ( q0o*gx + q2o*gz - q3o*gy) * h;
    q2 += ( q0o*gy - q1o*gz + q3o*gx) * h;
    q3 += ( q0o*gz + q1o*gy - q2o*gx) * h;

    /* 归一化：不做这一步，姿态会缓慢发散 */
    norm = sqrtf(q0*q0 + q1*q1 + q2*q2 + q3*q3);
    q0 /= norm; q1 /= norm; q2 /= norm; q3 /= norm;
}
```

> ⚠️ **符号自己验一次**：不同教材/代码库的叉积顺序有 `â × v̂` 与 `v̂ × â` 两种写法，差一个负号。
> **验证方法**：把板子慢慢倾斜，看解算出的 roll/pitch 是否**贴近真实倾角**；若越走越偏，就把 `Kp` 前的符号取反。

## 四、`Kp` 和 `Ki` 到底在调什么

| 参数 | 含义 | 调大 | 调小的后果 |
|---|---|---|---|
| `Kp` | **多信任加速度计**（把姿态往重力方向拉的速度） | 静止时收敛快、但**运动加速度会把姿态带偏**；振动大时会抖 | 收敛慢，长时间漂 |
| `Ki` | 消除**陀螺零偏**（低频误差） | 消除零偏快；过大会引入缓慢摆动 | 零偏长期存在，yaw/姿态慢慢漂 |

**经验值**（1000 Hz 采样）：`Kp` 量级 0.5~2，`Ki` 量级 0.001~0.01。
**先调 `Kp` 让它静止时快速贴合，再给一点点 `Ki` 消零偏。**

## 五、为什么用四元数，而不是欧拉角

| | 欧拉角 | 四元数 |
|---|---|---|
| 万向节死锁 | ❌ 会有（pitch 到 ±90° 时） | ✅ 没有 |
| 计算量 | 三角函数多 | ✅ 只有乘加 |
| 适合积分 | ❌ 微分方程复杂 | ✅ `q̇ = ½q⊗ω` 很干净 |

**结论**：内部运算用四元数，**只在"人看得懂的地方"转成欧拉角**（roll/pitch/yaw 显示、给控制器用）。

## 六、工程实践（这部分决定成败）

| 项 | 做法 |
|---|---|
| **采样周期** | ≥ 500 Hz~1 kHz，且**必须固定**（放定时器中断里，别放主循环） |
| **零偏标定** | 上电静止 1~2 秒，平均出三轴零偏，之后减去（**每次上电都做**） |
| **带宽配置** | 传感器内部的低通/带宽寄存器要按用途配：控制用低带宽，里程计用高带宽 |
| **安装误差** | IMU 的轴与车体轴不平行 → 用旋转矩阵标定，否则 yaw/pitch 系统性偏差 |
| **减震** | 车体振动直接进加速度计 → **机械减震（硅胶/减震柱）比任何算法都有效** |
| **运动加速度门限** | 检测 `\|a\|` 明显偏离 1g 时（加速/刹车/碰撞），**降低 `Kp`**，别让加计污染姿态 |
| **温漂** | 陀螺零偏随温度变；高精度场合要标温度曲线 |

## 七、常见坑

1. **量纲混用**：陀螺仪输出 `deg/s`，四元数积分要 `rad/s` → 忘了乘 `π/180`，姿态直接疯掉。
2. **四元数不归一化** → 姿态缓慢发散，表现为"越用越不稳"。
3. **`dt` 不稳定**（主循环里算，随任务负载变化）→ 解算精度时好时坏。
4. **指望加速度计修 yaw** → 物理上做不到（见第二节）。
5. **只信算法不信机械** → 振动导致的姿态噪声，**先减震，再调参数**。
6. **不同坐标系的姿态混用**：IMU 装在云台上 vs 装在底盘上，得到的 yaw **是两个不同的角**，做坐标变换时必须明确。
7. **直接用现成库但不理解** → 出问题无法排查。**至少要能说清这六步在干什么。**
