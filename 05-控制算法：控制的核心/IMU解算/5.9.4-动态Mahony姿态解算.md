# 5.9.4 动态 Mahony 姿态解算：误差反馈与加速度可信度

## 本章目标

用四元数表示三维姿态，以预测重力方向和加速度计方向之间的误差反馈修正陀螺仪，再积分得到新姿态。本例还会按加速度模长偏离 `1g` 的程度动态降低加速度校正强度。

> Mahony 是非线性互补滤波，不是简单地将一阶互补滤波的固定 `α` 换成动态 `α`。本章的加速度可信度降权是加在 Mahony 上的工程策略，用来降低明显运动加速度对姿态校正的污染。

## 坐标和单位约定

- 陀螺仪 `gx, gy, gz`：`rad/s`。
- 加速度计 `ax, ay, az`：单位为 `g`，水平静止时约为 `(0, 0, +1)`。
- `dt`：秒。
- 四元数存为 `(q0, q1, q2, q3)`，`q0` 是实部。
- 代码使用 `accel_gate_g` 控制模长门限。例如 `0.25g` 表示当 `| |a| - 1g |` 达到 `0.25g` 时，将加速度校正权重降至零。

若 IMU 输出为 `m/s²`，将 `accel_gate_g` 和期望模长相应改为 `m/s²`（门限例如约 `2.45 m/s²`），或先把加速度换算为 `g`。

## 计算步骤

1. 归一化加速度，得到测量方向。
2. 从当前四元数预测机体系中的重力方向。
3. 叉积计算方向误差 `e = â × v̂`。
4. 按加速度模长可信度缩放比例反馈，并以积分项补偿陀螺零偏。
5. 积分四元数并重新归一化。

可信度采用简单线性门限：

$$
c=\operatorname{clamp}\left(
1-\frac{|\|a\|-1g|}{g_{\text{gate}}},\,0,\,1
\right)
$$

当加速度模长接近 `1g` 时 `c` 接近 1；明显偏离时 `c` 变小，比例校正随之减弱。`c` 只根据模长判断，不能识别所有动态加速度：某些方向的运动加速度可能让模长仍接近 `1g`。

## C 函数

```c
#include <math.h>
#include <stdbool.h>
#include <stddef.h>

typedef struct {
    float q0, q1, q2, q3;        /* 姿态四元数 */
    float integral_x;
    float integral_y;
    float integral_z;            /* 积分反馈，单位 rad/s */
    float kp;                    /* 比例增益 */
    float ki;                    /* 积分增益 */
    float accel_gate_g;          /* 加速度模长降权门限，单位 g */
    float integral_limit;        /* 积分反馈限幅，单位 rad/s */
} MahonyFilter;

static float ClampFloat(float x, float low, float high)
{
    if (x < low) return low;
    if (x > high) return high;
    return x;
}

bool MahonyUpdate(MahonyFilter *filter,
                  float gx, float gy, float gz, /* rad/s */
                  float ax, float ay, float az, /* g */
                  float dt)                     /* s */
{
    if (filter == NULL || dt <= 0.0f ||
        filter->accel_gate_g <= 0.0f || filter->integral_limit < 0.0f) {
        return false;
    }

    const float accel_norm = sqrtf(ax * ax + ay * ay + az * az);
    float confidence = 0.0f;
    if (accel_norm > 1e-6f) {
        ax /= accel_norm;
        ay /= accel_norm;
        az /= accel_norm;
        confidence = ClampFloat(
            1.0f - fabsf(accel_norm - 1.0f) / filter->accel_gate_g,
            0.0f, 1.0f);
    }

    /* 预测的重力方向（与本章的四元数约定一致）。 */
    const float vx = 2.0f * (filter->q1 * filter->q3 -
                             filter->q0 * filter->q2);
    const float vy = 2.0f * (filter->q0 * filter->q1 +
                             filter->q2 * filter->q3);
    const float vz = filter->q0 * filter->q0 -
                     filter->q1 * filter->q1 -
                     filter->q2 * filter->q2 +
                     filter->q3 * filter->q3;

    /* e = measured_accel x predicted_gravity */
    const float ex = ay * vz - az * vy;
    const float ey = az * vx - ax * vz;
    const float ez = ax * vy - ay * vx;

    /* 可信时更新积分反馈；加速度失真时避免继续积累错误。 */
    filter->integral_x = ClampFloat(
        filter->integral_x + filter->ki * confidence * ex * dt,
        -filter->integral_limit, filter->integral_limit);
    filter->integral_y = ClampFloat(
        filter->integral_y + filter->ki * confidence * ey * dt,
        -filter->integral_limit, filter->integral_limit);
    filter->integral_z = ClampFloat(
        filter->integral_z + filter->ki * confidence * ez * dt,
        -filter->integral_limit, filter->integral_limit);

    gx += filter->kp * confidence * ex + filter->integral_x;
    gy += filter->kp * confidence * ey + filter->integral_y;
    gz += filter->kp * confidence * ez + filter->integral_z;

    /* q_dot = 1/2 * q ⊗ (0, gyro)；使用旧值同步更新。 */
    const float q0 = filter->q0;
    const float q1 = filter->q1;
    const float q2 = filter->q2;
    const float q3 = filter->q3;
    const float half_dt = 0.5f * dt;

    filter->q0 += (-q1 * gx - q2 * gy - q3 * gz) * half_dt;
    filter->q1 += ( q0 * gx + q2 * gz - q3 * gy) * half_dt;
    filter->q2 += ( q0 * gy - q1 * gz + q3 * gx) * half_dt;
    filter->q3 += ( q0 * gz + q1 * gy - q2 * gx) * half_dt;

    const float q_norm = sqrtf(filter->q0 * filter->q0 +
                               filter->q1 * filter->q1 +
                               filter->q2 * filter->q2 +
                               filter->q3 * filter->q3);
    if (q_norm < 1e-6f) {
        return false;
    }

    filter->q0 /= q_norm;
    filter->q1 /= q_norm;
    filter->q2 /= q_norm;
    filter->q3 /= q_norm;
    return true;
}
```

## 初始化和参数

静止且水平放置时，可先将四元数设为单位四元数，积分项清零；实际姿态不水平时，可先用加速度计估计 roll / pitch 初始化姿态。`kp`、`ki`、门限和积分限幅需根据采样率、传感器噪声与机械振动调试，不能把经验值当成通用常数。

`integral_limit` 可先设为一个有限的角速度上限以防积分饱和；若不使用积分补偿，可令 `ki = 0`。注意：加速度计只约束重力方向，积分项不能凭空观测 yaw 的真实航向，yaw 仍需要磁力计或其他航向参考。

## 限制与检查

- `|a|` 偏离 `1g` 是运动干扰的提示，不是可靠的运动检测器；模长恰好接近 `1g` 时，方向仍可能是错的。
- 叉积顺序、加速度计符号、坐标系和四元数方向必须匹配。静止放平后应收敛到期望倾角；小角度倾斜方向反了时，先核对轴向与符号，不要盲目增大 `kp`。
- `dt` 应来自实际采样间隔，最好由固定频率采样任务调用。
- 该示例没有磁力计融合，因此 yaw 长期漂移是预期行为。

## 验收

- [ ] 静止放置时，roll / pitch 能逐渐收敛到加速度计指示的倾角。
- [ ] 手动平移或振动时，模长偏离 `1g` 后，加速度校正会减弱。
- [ ] 陀螺仪仍负责快速变化；静止时不会因加速度计每次测量而直接跳变。
- [ ] 能解释动态降权是加在 Mahony 上的策略，而不是 Mahony 的定义。
