# 5.9.2 纯加速度计姿态解算：从重力方向估计倾角

## 本章目标

不使用陀螺仪，只从加速度计读数估计 roll 和 pitch。观察静止时倾角结果较稳定、响应较慢，而平移加速或振动会让结果失真。

## 输入和约定

- `ax, ay, az`：加速度计三轴读数；单位可以是 `g` 或 `m/s²`，公式只用方向，因此单位一致即可。
- 以下公式假设 IMU 水平静止时读数约为 `(0, 0, +1g)`，即加速度计测得的是比力。
- 输出角度单位为弧度，采用右手系。

若传感器水平静止时 `az` 为负值，说明器件输出或坐标约定相反，应先统一符号/轴向，再使用公式。

## 倾角公式

静止或匀速时，加速度计主要测到重力方向，可据此估计 roll 和 pitch：

$$
\begin{aligned}
\text{roll} &= \operatorname{atan2}(a_y,a_z)\\
\text{pitch} &= \operatorname{atan2}
  \left(-a_x,\sqrt{a_y^2+a_z^2}\right)
\end{aligned}
$$

```c
#include <math.h>
#include <stdbool.h>
#include <stddef.h>

typedef struct {
    float roll;   /* rad */
    float pitch;  /* rad */
} AccelTilt;

bool AccelEstimateTilt(float ax, float ay, float az,
                       AccelTilt *tilt)
{
    if (tilt == NULL) {
        return false;
    }

    const float norm_sq = ax * ax + ay * ay + az * az;
    if (norm_sq < 1e-12f) {
        return false; /* 零向量没有可用的重力方向 */
    }

    tilt->roll = atan2f(ay, az);
    tilt->pitch = atan2f(-ax, sqrtf(ay * ay + az * az));
    return true;
}
```

## 为什么它不适合单独跟踪运动姿态

加速度计测得的是比力。发生平移加速度、急转、碰撞或振动时，读数不再只代表重力方向。函数仍会把读数换算成角度，但这个角度可能不是实际倾角。

另外，重力方向不随绕竖直轴旋转而改变，所以加速度计**不能解算 yaw**。

## 怎么验证

1. 将 IMU 水平静置，确认 roll、pitch 接近零（若不接近，先检查轴向和符号）。
2. 分别绕 x、y 轴缓慢倾斜，确认输出方向和幅度与实际一致。
3. 保持姿态不变并平移或轻轻振动，观察结果受运动加速度影响。
4. 绕竖直轴旋转，确认单靠加速度计无法得到 yaw。

## 这一阶段的结论

- 加速度计可提供 roll / pitch 的重力参考，但不能提供 yaw。
- 它没有陀螺积分的长期漂移，却会把运动加速度当成重力方向变化。
- 下一步将用陀螺仪跟踪快速变化，再用加速度计的倾角慢慢校正漂移。
