# 2.1.0 电脑环境的整洁

> 开工之前，先把你的电脑"收拾干净"——环境整洁，后面调 bug 才能不迷路。

## 三条铁律
1. 所有下载的东西，不放 C 盘
2. 每个盘的文件夹，做好分类
3. SPR 的工具，统一放 D 盘或 E 盘下的 SPR 文件夹
